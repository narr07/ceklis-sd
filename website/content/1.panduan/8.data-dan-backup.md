## Lokasi data

Seluruh data tersimpan di laptop Anda:

```text
%APPDATA%\ceklis-sd\database.json   ← database
%APPDATA%\ceklis-sd\backups\        ← salinan cadangan
```

Buka folder ini dari **Profil → Database → Buka Folder Data**. Database ditulis secara aman: bila listrik padam saat menyimpan, file lama tetap utuh.

## Backup

- **Backup harian otomatis** dibuat saat aplikasi dibuka bila backup terakhir lebih dari 24 jam lalu. Bisa dimatikan di halaman Profil.
- Backup juga dibuat otomatis **sebelum impor, pulih, dan sinkronisasi**.
- Klik **Buat Backup Lokal** kapan saja. Aplikasi menyimpan 20 backup terbaru.
- Pilih **Pulihkan** pada salah satu backup untuk mengembalikan data ke kondisi saat itu.

## Pindah laptop

::steps
### Ekspor di laptop lama
**Profil → Database → Ekspor Database (.json)**. Simpan file di flashdisk atau penyimpanan awan sekolah.

### Impor di laptop baru
Pasang Ceklis SD, lalu **Profil → Database → Impor Database (.json)** dan pilih file tadi. Data di laptop baru diganti persis seperti isi file.
::

::caution
File ekspor berisi data pribadi guru dan siswa (NIP, NIK, tanggal lahir). Simpan di tempat yang aman dan jangan dibagikan di grup publik.
::

## Google Drive sekolah (opsional)

Hubungkan akun Google sekolah agar dokumen dan database tersimpan di Drive milik sekolah sendiri. Ceklis SD hanya meminta izin `drive.file`, jadi aplikasi hanya bisa melihat file yang dibuatnya sendiri. File lain di Drive Anda tidak bisa dibaca.

::steps
### Hubungkan akun
**Profil → Database → Google Drive → Hubungkan Google Drive**. Browser terbuka untuk masuk ke akun Google. Setelah mengizinkan, kembali ke aplikasi. Kunci akses disimpan di Windows Credential Manager laptop ini.

### Simpan dokumen
Tombol **Simpan ke Drive** muncul di template dokumen, SK Beban Mengajar & Jadwal, dan Daftar 1. Pilih PDF, Word, atau Excel. File masuk ke folder `Ceklis SD/Dokumen/<tahun ajaran dan semester>`. File bernama sama diperbarui, tidak digandakan.

### Buat kata sandi sinkron
Untuk menyimpan database, buat kata sandi sekolah (minimal 8 karakter). Database dienkripsi di laptop sebelum diunggah, sehingga isinya tidak bisa dibaca di Drive, termasuk oleh Google.

### Kirim dan ambil database
**Kirim ke Drive** mengunggah salinan terbaru. Di laptop lain, hubungkan akun yang sama, masukkan kata sandi, lalu pilih **Ambil dari Drive**. Bila NPSN di Profil masih kosong, ketik NPSN sekolah lalu pilih **Cari di Drive**.
::

::caution
Kata sandi sinkron **tidak bisa dipulihkan**. Bila lupa, salinan database di Drive tidak bisa dibuka lagi. Catat kata sandi di tempat aman yang diketahui kepala sekolah atau operator.
::

Backup lokal dibuat otomatis sebelum mengambil dari Drive. Bila database di Drive sudah diubah dari laptop lain sejak terakhir Anda ambil, aplikasi menanyakan apakah mengambil versi Drive atau menimpanya. Untuk melepas akun, pilih **Putuskan**. Kunci akses dan kata sandi dihapus dari laptop, sedangkan file di Drive tetap ada.

## Sinkronisasi server (opsional)

Sekolah atau dinas yang punya server sendiri bisa menyimpan salinan database di sana. Fitur ini mati sampai pengelola server memberikan **URL** dan **token khusus NPSN sekolah**. Token hanya disimpan di laptop Anda dan tidak ikut file ekspor maupun backup. Bila data di server sudah diubah dari perangkat lain, aplikasi menanyakan apakah mengambil data server atau menimpanya.
