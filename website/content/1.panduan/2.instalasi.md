## Kebutuhan

- Windows 10 atau 11, 64-bit.
- Ruang kosong sekitar 100 MB.
- Internet hanya untuk mengunduh installer.

## Memasang

::steps
### Unduh installer
Buka [halaman unduh](/#unduh) dan pilih **Installer .exe**. Paket **.msi** disediakan untuk pemasangan lewat kebijakan TI sekolah.

### Jalankan installer
Klik dua kali file yang diunduh. Installer memasang Ceklis SD untuk akun Windows Anda sendiri, jadi tidak perlu hak administrator.

### Lewati peringatan Windows
Bila muncul layar biru "Windows protected your PC", klik **Info lainnya** (More info), lalu **Tetap jalankan** (Run anyway). Penjelasannya ada di bagian berikut.
::

## Muncul peringatan virus atau "tidak aman"?

Installer Ceklis SD belum ditandatangani dengan sertifikat *code signing*. Akibatnya Windows dan browser belum mengenal penerbitnya, dan setiap versi baru dianggap file asing. Peringatan ini muncul karena file **belum dikenal**, bukan karena terbukti berbahaya.

| Peringatan | Penyebab | Yang perlu dilakukan |
|---|---|---|
| Browser: "file ini tidak umum diunduh" | File baru yang jarang diunduh | Edge: klik **⋯ → Simpan → Tetap simpan**. Chrome: klik **Simpan**/**Keep**. |
| SmartScreen: "Windows protected your PC" | Penerbit belum ditandatangani | **Info lainnya → Tetap jalankan**. |
| Defender atau antivirus menyebut *Trojan* (mis. `Wacatac`) | Deteksi otomatis keliru (*false positive*) pada program baru | Cek checksum di bawah. Bila cocok, pulihkan file dari **Keamanan Windows → Perlindungan virus & ancaman → Riwayat perlindungan**. |

Setiap versi dibangun otomatis oleh GitHub Actions dari [kode sumber publik](https://github.com/narr07/ceklis-sd), sehingga isinya bisa diperiksa siapa saja.

### Memastikan file asli

Bandingkan sidik jari SHA-256 file yang Anda unduh dengan yang tertera di [Catatan Rilis](/rilis). Buka PowerShell di folder unduhan, lalu jalankan:

```powershell
Get-FileHash .\Ceklis.SD_1.4.0_x64-setup.exe
```

Ganti nama file sesuai yang Anda unduh. Bila deretan huruf dan angka di kolom **Hash** sama persis dengan di Catatan Rilis, file tersebut asli dan tidak diubah siapa pun.

::caution
Unduh Ceklis SD hanya dari situs ini atau [GitHub Releases](https://github.com/narr07/ceklis-sd/releases). Jangan memasang installer kiriman grup atau situs lain yang checksum-nya tidak cocok.
::

## Memperbarui

Unduh installer versi terbaru dari [halaman unduh](/#unduh), lalu jalankan seperti biasa. Data Anda tidak terhapus karena tersimpan terpisah dari program. Perubahan setiap versi bisa dibaca di [Catatan Rilis](/rilis).

## Menghapus

Buka **Pengaturan Windows → Aplikasi → Aplikasi terinstal**, cari **Ceklis SD**, lalu pilih **Hapus instalan**. Folder data di `%APPDATA%\ceklis-sd` tidak ikut terhapus. Hapus folder itu secara manual bila memang tidak dibutuhkan lagi.
